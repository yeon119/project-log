# 10주차 웹 발표자료
약 6분, 총 9페이지. 화면 전환과 설명 호흡을 포함해 약 6분 분량입니다.

## 실행
index.html을 브라우저로 엽니다. 인터넷 연결과 설치 없이 실행됩니다.
- 좌우 방향키 / PageUp / PageDown: 페이지 전환
- G: 목차 / N: 발표자 메모 / F: 전체 화면
- 사진 클릭: 원본 확대
- 발표대본.md: 전체 발표 메모

## 내용 범위
10주차에 확인한 DB 등록·조회·중복 방지 및 규칙 미리보기까지입니다.
실제 WireGuard/nftables 자동 적용, 관리자 화면, 변경·재할당은 미구현으로 구분했습니다.
