## 1주차 프로젝트 소개 업데이트

1주차에는 WireGuard 기반 VPN 접근제어 및 이상행위 탐지 시스템의 소개 문서가 들어 있습니다. ‘이번 주차 편집’에서 본문을 수정할 수 있습니다. `##`는 큰 제목, `###`는 소제목, `**문구**`는 강조, `|`는 표의 칸 구분입니다. 시스템 구성도는 세 개의 백틱으로 감싼 영역이며 줄바꿈과 공백이 유지됩니다. 개발 기간과 날짜는 미정으로 남겨두었습니다.

작성자·기간·진행 단계 표시와 별도의 프로젝트 소개 영역은 제거했습니다. 프로젝트 정보 편집에서는 이름과 한 줄 설명만 바꿉니다. 기존 백업의 숨겨진 정보는 호환성을 위해 데이터에 남아 있습니다.

## 저장과 백업

수정 내용은 현재 브라우저의 localStorage에 저장됩니다. 같은 브라우저와 같은 주소로 다시 열면 유지됩니다. 저장에 실패하면 편집 창을 닫지 않고 오류를 표시합니다. 편집 중 취소하거나 창을 닫으면 확인을 요청합니다.

다른 컴퓨터나 다른 브라우저에서는 자동으로 동기화되지 않습니다. localhost와 127.0.0.1, 서로 다른 포트, 로컬 주소와 배포 주소는 별도 저장 공간입니다. 브라우저 데이터를 지우면 저장 내용이 없어질 수 있으므로 ‘백업 다운로드’로 JSON 파일을 보관하세요. 다른 기기에서는 ‘백업 불러오기’로 복원하세요. 불러오기는 기존 프로젝트 전체를 교체하므로 확인을 요청합니다.

이 버전은 로컬 편집용 정적 사이트입니다. 웹에서 저장한 내용은 원본 data.js 파일이나 배포된 사이트 전체에 자동 반영되지 않습니다. 여러 방문자에게 동일한 수정 내용을 제공하려면 별도 서버 저장 및 관리자 인증 기능이 필요합니다. 이번 버전은 배포하지 않았습니다.
