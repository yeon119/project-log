# 11주차 프로젝트 발표

9페이지 정적 웹 발표자료입니다. index.html을 브라우저에서 열면 됩니다.

GitHub Pages: 저장소의 week11 폴더 안에 이 파일들을 업로드하고, Settings → Pages에서 main 브랜치 /docs 폴더를 사용하려면 week11을 docs로 바꾸거나 저장소 루트에 파일들을 둡니다. 이미 Pages가 켜진 저장소에서는 기존 사이트를 덮어쓰지 않도록 week11 폴더를 유지하고 사이트의 /week11/ 주소로 접속합니다.

방향키로 페이지 이동, G 목차, N 발표자 메모, F 전체 화면. 사진을 클릭하면 원본을 볼 수 있습니다.
